# 💅 ระบบจองคิวทำเล็บออนไลน์
ระบบจองคิวฟรี เชื่อม Google Sheets + แจ้งเตือน LINE Notify

## ใช้งาน
1. เปิด `index.html` ในเบราว์เซอร์
2. ตั้งค่า `APPSCRIPT_URL` ในส่วน `<script>` เป็นลิงก์ Google Apps Script ของคุณ
3. ตั้งค่า LINE Notify Token ใน Google Apps Script
